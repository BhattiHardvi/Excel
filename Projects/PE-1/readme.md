
# Retail Sales Excel Dashboard Project

## Project Overview
This project analyzes retail sales data using Microsoft Excel. It includes data cleaning, sales analysis, advanced Excel formulas, charts, and an interactive dashboard.

## Dataset
- Dataset: Retail_Sales_Dashboard_Practice.xlsx
- Sheet: Sample_Data
- Total Records: 1,000
- Total Original Columns: 12

## Project Tasks

### 1. Dataset Selection & Import
- Imported the provided retail sales dataset.
- Preserved original data in Raw_Data.

### 2. Data Cleaning & Preparation
- Checked duplicate records.
- Checked missing values.
- Removed unnecessary spaces from text.
- Standardized date and numeric formats.
- Created Year, MonthNo, and Month columns.

### 3. Sales Analysis
Created summary tables for:
- Sales by Category
- Sales by Country
- Sales by Customer Segment
- Monthly Sales
- Sales by Payment Method

### 4. Advanced Excel Formulas
Implemented:
- VLOOKUP
- INDEX and MATCH
- IF
- Nested IF
- COUNTIF
- SUMIF

### 5. Data Visualization
Created:
- Sales by Category Bar Chart
- Monthly Sales Trend Line Chart
- Conditional Formatting

### 6. Interactive Dashboard
Created an interactive dashboard with:
- Total Sales
- Quantity Sold
- Total Transactions
- Average Sale

Dashboard filters:
- Country
- Category
- Customer Segment
- Month

### 7. Documentation
Added project documentation and instructions in the Documentation worksheet.

## Workbook Structure

| Sheet Name | Description |
|---|---|
| Dashboard | Interactive dashboard |
| Raw_Data | Original dataset |
| Cleaned_Data | Cleaned dataset |
| Pivot_Analysis | Sales summary tables |
| Formula_Practice | Advanced Excel formulas |

## Tools Used
- Microsoft Excel
- Excel Formulas
- Pivot-style Analysis
- Charts
- Conditional Formatting

## How to Run
1. Download the Excel workbook.
2. Open it in Microsoft Excel.
3. Go to the Dashboard sheet.
4. Select filters from the dropdown lists.
5. Analyze the KPI cards and charts.
6. Check Formula_Practice for formula examples.
7. Visit Pivot_Analysis for sales summaries.

This project demonstrates Excel skills in data import, cleaning, analysis, formulas, visualization, and interactive dashboard development.
