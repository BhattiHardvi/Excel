# PR Final Project – Data Intelligence Dashboard

## Project Overview
The Data Intelligence Dashboard is an Excel-based project designed to analyze customer transaction data, identify business insights, and present sales performance through charts and dashboards.

## Dataset Information
- **Dataset Name:** Final Project Dataset
- **Total Records:** 250
- **Unique Customers:** 50
- **Products:** 10
- **Data Type:** Customer Transaction Data

## Project Objectives
- Analyze customer transactions.
- Calculate total revenue and average order value.
- Identify top customers and most sold products.
- Analyze regional sales performance.
- Find frequently purchased products.
- Create visualizations and an interactive-style dashboard.
- Generate meaningful business insights.

## Workbook Structure

### 1. Raw Data
Contains the original customer transaction records and additional calculated columns:
- Year
- Month
- Customer Tenure
- Timestamp
- Name Abbreviation
- Value Group

### 2. Analysis
Includes:
- Total Revenue
- Total Transactions
- Unique Customers
- Units Sold
- Average Order Value
- Revenue by Region
- Revenue by Product
- Customer Value Ranking
- Regression Analysis
- Date and Time Functions
- What-If Analysis

### 3. Visualizations
Contains the following charts:
- Bar Chart – Revenue by Region
- Pie Chart – Revenue Share by Product
- Line Chart – Monthly Revenue Trend

### 4. Dashboard
Displays important business information:
- KPI Indicators
- Top 10 Customers
- Top Products
- Highest Revenue Region
- Most Purchased Product
- Sales Charts

### 5. Comparison
Includes:
- Comparison of two customer name lists.
- Matching names using COUNTIF.
- Name abbreviations using TEXT functions.

### 6. Read Me
Contains project documentation and instructions.

## Excel Functions Used

| Function | Purpose |

| TODAY() | Current date |
| NOW() | Current date and time |
| DATEDIF() | Calculate date difference |
| EOMONTH() | Find month-end date |
| FILTER() | Filter multiple records |
| IF() | Apply conditions |
| SUMIF() | Calculate conditional totals |
| SUMIFS() | Calculate multiple-condition totals |
| COUNTIF() | Count matching records |
| LEFT() | Extract left characters |
| RIGHT() | Extract right characters |
| LEN() | Count characters |
| FIND() | Find character position |
| SLOPE() | Calculate regression slope |
| INTERCEPT() | Calculate regression intercept |
| RSQ() | Calculate R-squared |
