# Sales Data Analyzer

## Project Overview

The **Sales Data Analyzer** is an Excel-based project that organizes and
analyzes sales records to understand customer purchases, sales by
region, product category performance, profit, and monthly sales trends.

The project is created using Microsoft Excel. It does not require
Python.

## Workbook

**File name:** `Analayzer.xlsx`

The workbook contains three worksheets:

### 1. Dataset

Contains 200 sales records with the following columns:

-   `Customer_ID`
-   `Customer_Name`
-   `Region`
-   `Product_Category`
-   `Sales`
-   `Quantity`
-   `Discount`
-   `Order_Date`
-   `Profit`

### 2. Analyzer

This worksheet contains the detailed analysis:

-   Customer-wise total purchase
-   Customer discount and total profit
-   High-value customer identification
-   Regression statistics and ANOVA output
-   Descriptive statistics for Sales, Quantity, and Discount
-   Monthly sales and sales growth analysis
-   Pivot-style summary of sales by region and product category
-   Bar, line, and pie chart areas

### 3. Dashboard

The dashboard presents key sales indicators and summaries:

-   Total Sales
-   Total Profit
-   Region-wise sales
-   Product category-wise sales

## Excel Features and Functions Used

The workbook uses Excel features such as:

-   `SUM` -- calculates totals
-   `SUMIF` -- calculates customer-wise purchase totals
-   `INDEX` and `MATCH` -- identifies a customer based on the highest
    purchase
-   Descriptive Statistics -- summarizes sales, quantity, and discount
-   Regression and ANOVA -- provides statistical analysis
-   Pivot Table -- summarizes sales across regions and product
    categories
-   Charts -- presents sales information visually

## How to Use

1.  Open `Analayzer.xlsx` in Microsoft Excel.
2.  Select the **Dataset** worksheet to view the sales records.
3.  Select the **Analyzer** worksheet to explore detailed calculations
    and statistical analysis.
4.  Select the **Dashboard** worksheet to view the sales summary and
    visual presentation.

## Conclusion

This project demonstrates how Microsoft Excel can be used for sales data
analysis. It helps summarize customer purchases, compare regional and
product category sales, examine profitability, and present important
business information through a dashboard.
